# Yaad-Dehani

Yaad-Dehani (یاد دہانی) is a fully client-side React todo, calendar, and reminder app. It stores tasks in browser IndexedDB through Dexie and does not require a server.

## Scripts

- `npm run dev` starts the local Vite dev server.
- `npm run build` creates the production build.
- `npm run test` runs unit and component tests.
- `npm run test:e2e` runs Playwright checks.
